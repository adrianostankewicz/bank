# ADR-002: Introdução de Transaction como entidade de domínio

## Status
Accepted

## Contexto
Durante o desenvolvimento, identificamos que manter balance como atributo
direto de Account limitaria a evolução do sistema. O requisito de código
maleável e a complexidade da operação de transferência — que exige atomicidade
entre duas contas — evidenciaram a necessidade de uma modelagem mais robusta.

## Decisão
Introduzir Transaction como entidade de domínio. Cada operação financeira
(deposit, withdraw, transfer) gera uma Transaction imutável. Balance passa
a ser derivado das transactions associadas à conta.

## Consequências
- Rastreabilidade completa de cada operação financeira
- Balance calculável para qualquer período
- Transferência naturalmente atômica — duas transactions em uma única operação
- Maior complexidade na camada de domínio e nos usecases
