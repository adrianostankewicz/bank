# ADR-001: Balance como atributo direto de Account

## Status
Superseded by ADR-002

## Contexto
Início do projeto, mapeamento inicial do domínio financeiro.
A spec da API retorna balance como campo no response da conta,
o que sugeriu modelar balance diretamente na entidade Account.

## Decisão
Balance mantido como atributo direto de Account do tipo Money.
Métodos Deposit e Withdraw modificam o saldo diretamente na entidade.

## Consequências
- Implementação simples e aderente ao contrato da API
- Baixa complexidade inicial
- Fácil de testar e evoluir dentro do escopo atual da spec
