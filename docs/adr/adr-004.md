# ADR-004: Reconciliação pós-transferência

## Status
Proposed

## Contexto
Durante o desenvolvimento do TransferUseCase, identificamos que após salvar
as transactions de débito e crédito, não há validação de que os saldos
resultantes batem com os valores esperados.

## Decisão
Não implementar reconciliação automática pós-transferência no escopo atual.
A compensação de falha é feita via Credit na conta origem caso o Credit
no destino falhe.

## Consequências
- Menor complexidade no usecase
- Em produção, reconciliação deveria ser implementada como processo assíncrono
- Um job periódico calcularia o saldo de todas as contas e validaria consistência
- Divergências seriam alertadas para análise manual
- Próximo passo natural antes de ir para produção
