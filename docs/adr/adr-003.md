# ADR-003: Separação entre EventType e TransactionType

## Status
Accepted

## Contexto
Durante o desenvolvimento do domínio financeiro, identificamos dois conceitos
distintos que convergem no mesmo fluxo: o tipo de evento que chega pela API
e o tipo de movimento contábil registrado internamente.

## Decisão
Separar em dois tipos distintos:
- EventType — define qual operação o sistema executa, vive na camada HTTP/dispatcher
- TransactionType — registro contábil imutável, vive no domínio (Credit, Debit, Reversal)

## Consequências
- Domínio financeiro desacoplado do transporte HTTP
- Transaction como registro contábil puro, sem conhecimento de eventos externos
- EventType pode evoluir sem impactar o domínio
- Novos tipos de evento não exigem mudança no modelo de Transaction
